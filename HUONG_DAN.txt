HƯỚNG DẪN DÙNG (Windows) - Chấm công VDL VN
============================================

1. GIẢI NÉN
   Bấm chuột phải vào file zip, chọn Extract All, giải nén vào
   C:\ChamCongVDL (đường dẫn ngắn cho an toàn).
   Không chạy trực tiếp trong file zip.

2. CHẠY
   Bấm đúp BAT_DAU.bat  -> chạy web + tạo link public (dùng khi cần
   cho máy khác truy cập qua internet).
   Bấm đúp Chay_web.bat -> chỉ chạy trong máy/LAN, không link public.

   Cửa sổ đen hiện ra, đợi vài giây trình duyệt tự mở
   http://127.0.0.1:8000
   Giữ cửa sổ đen mở trong lúc dùng. Tắt: bấm Ctrl+C hoặc đóng cửa sổ.

3. ĐĂNG NHẬP
   Quản trị: admin / admin@2026
   Nhân viên: nvXX / vdl@XX  (XX là Pers.no, ví dụ nv10 / vdl@10)
   Danh sách đầy đủ ở data\credentials.csv sau lần chạy đầu.
   Nên đổi mật khẩu trong trang Tài khoản sau khi dùng thử.

4. LINK PUBLIC
   Khi chạy BAT_DAU.bat, tên link lấy từ TEN_LINK_PUBLIC.txt.
   Link và mật khẩu tunnel hiện trong cửa sổ đen, đồng thời lưu ở
   data\public-link.txt. Link đổi mỗi lần chạy lại.

5. DỮ LIỆU
   data\app.db          : database (nhân viên, giờ công, tài khoản)
   data\timesheets\     : file Excel từng người, tự cập nhật khi lưu giờ
   data\source\         : file Excel mẫu của công ty (đừng xoá)
   data\backups\        : bản sao database tự tạo mỗi ngày, giữ 7 bản
   Muốn sao lưu hoặc chuyển máy: copy cả thư mục data.

6. LỖI THƯỜNG GẶP
   - Trình duyệt báo lỗi kết nối: đợi 10 giây bấm F5. Nếu vẫn lỗi, xem
     file log.txt cạnh BAT_DAU.bat.
   - Upload file Excel báo "file đang được mở": đóng file đó trong Excel
     rồi upload lại.
   - Windows chặn file: bấm chuột phải vào file .bat, chọn Properties,
     tick Unblock.
   - Cổng 8000 bận: tắt cửa sổ chạy web cũ rồi chạy lại.

7. LƯU Ý
   - Máy phải bật thì web mới chạy. Muốn chạy 24/7 phải dùng máy chủ
     hoặc VPS.
   - Không đưa link public cho người ngoài, dữ liệu chấm công là dữ liệu
     cá nhân của nhân viên.
